# Voorbeeldafbeeldingen

Zet hier je eigen voorbeeldafbeeldingen neer (liefst in de verhouding van een MacBook-scherm, bijvoorbeeld 1540×1000) en koppel ze in `js/config.js` aan een wallpaper:

```js
image: "images/noir-marble.jpg",
```

Zolang er geen afbeelding is ingesteld, of als het bestand niet gevonden wordt, tekent de site zelf een voorbeeld in de stijl en kleuren van die wallpaper.

Zet hier **alleen kleine voorbeelden** neer. Alles in deze map staat openbaar online, dus de volledige bestanden die je na betaling verstuurt horen hier niet. Deel die via een downloadlink (bijvoorbeeld Google Drive, Dropbox of WeTransfer).
